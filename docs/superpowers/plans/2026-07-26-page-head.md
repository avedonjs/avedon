# Per-page `<head>` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let `load` return `head: { title, description, html }` so each route renders its own `<title>` / `<meta name="description">`, including the avedon docs site.

**Architecture:** Add a `HeadMeta` type in `@avedon/shared`. Teach `renderShellPrefix` / `renderShell` (in `packages/server/src/ssr.ts`) to replace-or-append title and description in `app.html` and append raw head HTML. The pipeline extracts `head` from the load result and injects it on every path that already awaits `load` (SSG, CSR, `bufferHtml`); streaming SSR opts in per route with `awaitHead: true`, and fails loudly in dev when a route returns `head` without opting in.

**Tech Stack:** TypeScript, Vitest, Playwright, existing `@avedon/server` pipeline and `@avedon/shared` types.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-26-page-head-design.md`.
- Stay on `main`; commit only when the user asks (all commits are batched at the end of this effort).
- `title` and `description` are HTML-escaped; `head.html` is trusted raw HTML (same contract as `{@html}`, see `docs/security.md`).
- Do **not** change streaming defaults for routes without `awaitHead`: `e2e/ttfb-smoke.mjs` thresholds must pass unchanged.
- Fallback: without `head.title`, the `<title>` already in `app.html` stays.
- Verify with `pnpm build && pnpm test && pnpm typecheck`, then `pnpm test:smoke` and `npx playwright test`.

```ts
export function renderShell(
  appHtml: string,
  options: {
    body: string
    head?: HeadMeta
    css?: string
    props?: Record<string, unknown>
    clientEntry?: string
  },
): string {
  return (
    renderShellPrefix(appHtml, { head: options.head, css: options.css }) +
    options.body +
    renderShellSuffixFromTemplate(appHtml, {
      props: options.props,
      clientEntry: options.clientEntry,
    })
  )
}

export function renderShellPrefix(
  appHtml: string,
  options: { head?: HeadMeta; css?: string } = {},
): string {
  const extra: string[] = []
  let html = appHtml

  if (options.head) {
    const applied = applyHead(html, options.head)
    html = applied.html
    extra.push(...applied.extra)
  }
  if (options.css) extra.push(`<style data-avedon-css>${options.css}</style>`)

  const head = extra.filter(Boolean).join('\n')
  if (!html.includes('%avedon.head%')) {
    html = html.replace('</head>', `${head}\n</head>`)
  } else {
    html = html.replace('%avedon.head%', head)
  }
  // … keep the remaining %avedon.body% / '<div id="app">' logic exactly as-is
```

Keep everything after the head substitution unchanged (the `%avedon.body%` split and return).

Add below:

```ts
/** Replace title / description in the template when present; return leftovers to append. */
function applyHead(appHtml: string, head: HeadMeta): { html: string; extra: string[] } {
  let html = appHtml
  const extra: string[] = []

  if (head.title != null) {
    const tag = `<title>${escapeHtml(head.title)}</title>`
    if (/<title>[\s\S]*?<\/title>/i.test(html)) {
      html = html.replace(/<title>[\s\S]*?<\/title>/i, tag)
    } else {
      extra.push(tag)
    }
  }

  if (head.description != null) {
    const tag = `<meta name="description" content="${escapeHtml(head.description)}" />`
    const re = /<meta\s+name=["']description["'][^>]*>/i
    if (re.test(html)) {
      html = html.replace(re, tag)
    } else {
      extra.push(tag)
    }
  }

  if (head.html) extra.push(head.html)
  return { html, extra }
}
```

/** Split `head` out of a load result; returns the head and the remaining page data. */
function takeHead(data: Record<string, unknown>): { head?: HeadMeta; data: Record<string, unknown> } {
  const raw = data.head
  if (!raw || typeof raw !== 'object') return { data }
  return { head: raw as HeadMeta, data }
}

4. **Opt-in enforcement** — after the load data is known on a non-`awaitHead` streaming route, before writing the body:

```ts
function assertHeadOptIn(
  options: HandlerOptions,
  route: RouteConfig,
  data: Record<string, unknown>,
): void {
  if (route.awaitHead || route.bufferHtml) return
  if ((route.render ?? 'ssr') !== 'ssr') return
  if (!data.head || typeof data.head !== 'object') return
  const msg = `load() returned "head" for ${route.path} but the route does not set awaitHead: true — the shell may flush before the head is known.`
  if (options.dev) throw new Error(msg)
  console.warn(`[avedon] ${msg}`)
}
```

Call it in the streaming path for both the `early.kind === 'data'` branch and the late `final.kind === 'data'` branch, immediately before rendering the body.

`load` may return a `head` object next to `data` to control the document head:

### `awaitHead: true`

Streaming SSR flushes the document shell before `load()` finishes, so a `head` returned by `load` would arrive too late. Set `awaitHead: true` on the route to wait for `load()` before flushing the shell — the body still streams and `{#await}` boundaries still work.
